# Contributing

* Make an anonymous Gmail account for yourself with a name similar to "Junker Jörg," make a GitHub account using that Gmail account, fork this project, set your local git config identity to that anonymous account (`git config set user.name junkerjorg`, and `git config set user.email junkerjorg@gmail.com`), and make pull requests from your fork.  When someone asks, "Who is Junker Jörg?", we can all say "I am Junker Jörg!"
* You can propose a new feature by submitting a pull request containing the feature's description, issue, or implementation.
* Feature descriptions and issues should be in Markdown files versioned with the code, for AI agents to use and to facilitate decentralized development.  See FEATURES.md and `issues/*.md`.
* The GitHub project owner approves new features
