# Book of Discipline Reference

The workflows, roles, and data structures in this application are modeled after the ecclesiastical discipline process defined by the Orthodox Presbyterian Church (OPC).

## Canonical Resource

The primary and canonical guide for all processes is the **Book of Discipline of the Orthodox Presbyterian Church**:
- **URL**: [https://opc.org/BCO/BD.html](https://opc.org/BCO/BD.html)

## Application Mapping

When implementing issues, features, and database schemas:
1. **Terminology**: Use BCO Book of Discipline terminology (e.g., *Matter*, *Case*, *Charge*, *Specification*, *Objection*, *Appeal*, *Complaint*, *Overture*, *Judicatory*).
2. **Roles**: Ensure user roles match those defined in the BCO (e.g., *Accuser*, *Accused*, *Witness*, *Counsel*, *Judicatory*, *Amicus Curiae*).
3. **Workflow Rules**: Procedural steps (such as Matthew 18 reconciliation, preliminary investigations, and filing deadlines) must align with the BCO regulations.
